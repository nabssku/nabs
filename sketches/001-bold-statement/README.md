# Variant 1: Bold Statement (sketches/001-bold-statement/)

## Design Stance
Massive typography-driven hero that dominates the viewport (90vh minimum), minimal visual distractions, content hits hard with commanding presence and high-contrast Neo-Brutalism aesthetics.

## Key Choices
- **Typography**: Space Grotesk at massive display sizes (up to 8xl) with tight leading for powerful headings.
- **Color Palette**: Cream background (`#FFFDF7`), stark black borders, with vibrant pop accents (Yellow `#FDE047`, Pink `#F472B6`, Green `#86EFAC`, Blue `#93C5FD`, Orange `#FB923C`).
- **Layout & Sections**: Full-viewport hero with floating status badge; 60/40 side-by-side About section with prominent avatar; Bento grid for featured projects; horizontal sticker strip for tech stack and skills; interactive contact form with instant success feedback.
- **Interactive Elements**: Floating notification sticker, hover translation on buttons and bento cards, mobile menu toggle, interactive contact form confirmation state.

## Trade-offs
- **Pros**: Extremely high visual impact, instantly memorable, creates a confident and authoritative developer persona.
- **Cons**: Takes up considerable vertical space in the hero before the user encounters secondary content.

## Best For
Developers looking to make an unforgettable first impression, highlighting flagship SaaS/AI projects with bold typography and punchy layouts.
